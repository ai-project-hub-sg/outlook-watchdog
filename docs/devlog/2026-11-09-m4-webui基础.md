## 1. 背景

按 design.md §7 实现 WebUI 基础版：登录/会话/CSRF、大盘、账号 CRUD、账号详情（历史/手动检查/基线）、告警列表、设置、通道管理。保持单二进制（go:embed 模板+htmx+CSS，无 node 构建链）。

## 2. 修改情况

- 代码：
  - `internal/web`：Server（ServeMux 路由、session 认证、CSRF（session 派生 token）、bcrypt 密码、登录限速 5 次/10min、安全头）；页面 dashboard/accounts/account/alerts/settings/channels/setup/login
  - `internal/web/templates|static`：8 页面 + htmx.min.js + style.css（深色极简）
  - `internal/store`：新增 SetAccountEnabled、ListRuns+listResults（详情页历史）、Session CRUD、RunWithResults
  - `cmd/watchdog`：`serve` 命令实现（调度 Loop goroutine + http.Server，ctx 优雅停机）
- 配置 / 文档：settings 表新增 `admin.password_hash` 键（setup 流程写入）
